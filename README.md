# Zahando Eraser 🖐️

A browser extension that lets you erase any HTML element from a webpage with a single click — without opening DevTools.

Inspired by the power of **The Hand** from *JoJo's Bizarre Adventure*, Zahando Eraser removes unwanted page elements with a satisfying Za Hando sound effect.

## Features

- 🖐️ Click any HTML element to erase it instantly
-  No need to open Developer Tools
- Fast and lightweight
- Plays a Za Hando sound effect when removing elements
- Works on almost any webpage
- Useful for removing:
  - Ads
  - Popups
  - Annoying banners
  - Unwanted sections
  - Distractions

## How It Works

1. Activate Zahando Eraser
2. Hover over any element on a webpage
3. Click the element you want to remove
4. **ZA HANDO!** 🖐️
5. The element disappears
